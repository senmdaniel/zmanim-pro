# Loxone Zmanim Pi

Offline zmanim API voor Raspberry Pi + Loxone integratie.

## Features
- Shkia (sunset)
- Candle lighting
- Tzeit hakochavim
- Offline werking
- JSON API

## Install

```bash
git clone https://github.com/jouwnaam/loxone-zmanim-pi
cd loxone-zmanim-pi
pip3 install -r requirements.txt
python3 app.py
